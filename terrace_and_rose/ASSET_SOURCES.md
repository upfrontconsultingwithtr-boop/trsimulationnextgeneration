# Asset sources and licenses — Terrace & Rose

**Third-party assets:** the realistic human characters use MakeHuman community asset packs, all **CC0 1.0** (public domain dedication; no attribution required — credited below anyway). Everything else is original to this project. Each one is generated by
`tools/blender/build_assets.py` (Blender 4.2 LTS, GPL tool; its *output* belongs to this project) or built in code.
These assets are released with the project under CC0 1.0 unless the project owner picks another license.
